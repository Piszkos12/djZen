djZen

One-click "DJ Zen mode" for Windows laptops. Silence the system, stop the dropouts – and get every setting back afterwards.

Download djZen 0.1.0 for Windows (64-bit)

Windows 10 / 11 · free and open source (GPL-3.0) · all releases · source code

What it does

QuietTurns off notifications, Windows event sounds and call ducking.
No dropoutsDisables USB selective suspend, PCIe power saving, sleep and CPU down-clocking.
Fewer latency spikesSwitches off Wi-Fi and Bluetooth, pauses Windows Update, search indexing and SysMain.
Your DJ software firstProtects rekordbox, Serato, Traktor, VirtualDJ, Mixxx or djay and raises its priority.

Safe by design

  • Everything is restored. The original state is saved before any change and survives a crash or reboot. If djZen did not shut down properly, it offers to restore on the next start; djZen.exe /restore works from the command line too.
  • Security software is never touched – Defender, firewall and antivirus are off-limits, even optionally.
  • Profiles: Offline zen, Streaming zen, Home practice – or save your own.

Install

  1. Download and unzip to a folder of your choice.
  2. Run djZen.exe (it asks for administrator rights).
  3. Pick a profile and your DJ software, then press ZEN. Test it at home first.
Windows warning on first start: djZen is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC" (choose More info → Run anyway), and Smart App Control, if enabled, blocks it. You can build it yourself from the source code.
